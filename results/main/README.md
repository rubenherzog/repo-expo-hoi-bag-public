# Main k10 local delivery

This directory contains historical lightweight paper-table intermediates. The
files `Supplementary_Tables_main_local_v5.xlsx` and
`Supplementary_Tables_main_k10_awaiting_diagnosis_balance.xlsx` are retained as
frozen pre-consolidation inputs, not as the current delivery.

The consolidated workbook, figures, source data, audit and manifest are under
`outputs/main/paper/complete/`. Heavy candidate metrics, OOF predictions,
resampling draws, checkpoints and logs remain under the canonical external
runtime.
